### 🛠️ Featured Projects

**Dhakal Traders — Business Management System**
Full POS and accounting suite: role-based access (Owner/Admin/Cashier), billing terminal, customer/supplier management, and a full accounting module (P&L, Balance Sheet, VAT Report, Cash Book). React + TypeScript frontend with bilingual Nepali/English support and thermal receipt printing; MongoDB Atlas backend.

**BS International Production Tools**
In-house production management system for a garment manufacturer — tracks cost sheets and worker logs across garment types using the Nepali (B.S.) calendar, plus a color-count sheet tool for the finishing department.

**Personal Portfolio**
Server-side rendered site running on Cloudflare Workers with a D1 database, built from scratch. → [nabindhakal28.com.np](https://nabindhakal28.com.np/)

**Recipe Nest & Chef Portal**
MERN-stack academic project built for Patan College coursework (CIS051-2).
